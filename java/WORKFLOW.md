Workflow for writing Java bindings
===
This document will guide you step-by-step on how to write the Java bindings by utilising the C wrapper. The goal is to write the library as object-oriented, mimicking the original C++ library. It is better if you read this document while looking at the source code to get better understanding.

Important files and directories
---
(You may rename the files and directories)
1. `src/main/java/mylib/binding/handles/` contains code for every handles. It also manages handle disposal.
2. `src/main/java/mylib/binding/refs/` contains helper classes to pass values for int* (`IntRef`) and char* (`CharRef`) in C.
3. `src/main/java/mylib/binding/*Native.java` contains the binding to native Java functions **(important!!!)**. It used to generate JNI headers.
4. `src/main/java/mylib/binding/Loader.java` stores the **JNI library filepath** to be loaded.
5. `src/main/java/mylib/exceptions/` contains custom exceptions.
6. `src/main/java/mylib/internal/StatusHelper.cs` translates status codes into Java exceptions.
7. `src/main/jni/*.h*` are JNI headers generated by `javac`. It generates from `*Native.java` files which has `native` keyword.
8. `src/main/jni/helpers/` contains helpers for `IntRef` and `CharRef` Java objects (see `binding/refs/`).
